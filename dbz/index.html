🍎 How to set as macOS Screen Saver

Follow these 3 easy steps to turn this dynamic Dragon Ball Z fight into your official MacBook screensaver:

  1. Option A: Native Web Saver Plugin (Recommended)
    Install WebViewScreenSaver or Aerial Web Saver for macOS, then add this URL: http://localhost:5173
  2. Option B: Instant Fullscreen Browser Saver
    Open this app in Safari or Chrome, press F to go fullscreen. When you step away from your Mac, mouse hides & screensaver mode auto-activates!
  3. Keyboard Shortcuts Cheat Sheet
    • [SPACE] : Super Beam Clash Boom!
    • [C] : Cycle Character Transformations (SSJ / Blue / UI / Golden)
    • [A] : Switch Battle Arenas (Namek / TOP / Wasteland / Chamber)
    • [F] : Toggle Fullscreen
    • [1, 2, 3] : Switch Character Matchups (Goku vs Vegeta / Goku vs Frieza / Vegeta vs Broly)
    • [M] : Mute / Unmute Energy Audio SFX
